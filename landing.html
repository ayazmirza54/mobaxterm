03Re-run

  

    
Run it twice.
Nothing installs twice.

    
Every step checks before it installs. Add a tool to the sentence next month, regenerate, run the same script again. Only the new thing happens.

    
0installed

    

      
pwsh~/devbox

      

    

    
The first run installs each tool and marks it with a check. The second run finds each tool already installed and skips it.

Is the script safe to run again?
Yes. Each step checks whether the tool is already there and skips it if so. That's the whole point.

      
Which machines?
Windows (PowerShell 7 or Git Bash, plus optional WSL), Ubuntu, and macOS. Or a Dockerfile or devcontainer.

      
Where do my picks go?
Into your browser's local storage, and nowhere else. Close the tab, come back, they're still there.

      
Something missing?
If it installs from winget, apt, Homebrew or a plain installer script, it can be a recipe. Invite-only tools stay out.
